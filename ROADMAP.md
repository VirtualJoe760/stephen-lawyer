# Roadmap

Items captured out of v1 scope per the build prompt §12:

- Wholesale portal
- Multi-currency display (Stripe will charge USD; international shipping supported)
- Loyalty / rewards
- Customer-uploaded designs / custom orders
- Admin dashboard (use Stripe Dashboard, Printful Dashboard, Sanity Studio directly for v1)

- Loyalty tier ("Frequent Flyer")
